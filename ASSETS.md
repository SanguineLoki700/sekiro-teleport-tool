# Artwork

The interface artwork and SEKIRO / TELEPORT logo were generated and edited from supplied Sekiro references. The brush textures use the same artwork with transparent backgrounds.

`sekiro.ico` is the original repository icon. `assets/sekiro-original.ico` is the copy used by the window.

This is an unofficial fan project, not affiliated with FromSoftware or Activision. No game archives or fonts are included.
